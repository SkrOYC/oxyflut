# Locale and direction flow

## Mapping

`CAP-I18N-001`: When locale or text direction changes, the system must propagate locale, render bidirectional text, and mirror directional layout where required.

## Behavior

```mermaid
flowchart LR
    Change[Locale or direction change] -->|normalized event| Runtime[Component runtime]
    Runtime -->|locale context| Text[Text and editing]
    Runtime -->|direction context| Layout[Layout and viewport]
    Text -->|bidirectional runs| Scene[Scene composition]
    Layout -->|mirrored geometry| Scene
    Runtime -->|language and direction| Semantics[Semantics]
```

## Failure path

If locale data or direction is invalid, the runtime retains the last valid context and doesn't publish a partially mirrored view.
